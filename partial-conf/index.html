About the conference

Partial is a conference about modern functional programming languages and technologies for the web. Think Erlang, Elixir, Clojure, ClojureScript, Haskell, Elm,PureScript, F#, React and many more. It’s a conference that can get you outside your comfort zone and let you learn something new.
